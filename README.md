Work-Buddy: A productivity app designed to help you stay on top of your tasks, notes, and time management in one place.

Description
This project was developed as a response to an increased workload at my current job. I was managing tasks from various sources, such as Xetech, Basecamp, and email. At times, it became difficult to keep track of everything.
After speaking with coworkers, I decided to create a centralized system that could help us all stay organized and on top of our projects.

This tool helps users:
- Manage tasks across various categories.
- Set deadlines and track task completion.
- Use a Pomodoro timer to stay focused.
- Create and organize notes in a simple, visual way.

Features
- Task creation, categorization, and deadline setting.
- Pomodoro timer to boost focus and productivity.
- Notes system with color coding for easy organization.

Installation
Clone the repository:

git clone https://github.com/yourusername/productivity-hub.git

Install dependencies:
npm install

Run the app:
npm start
Navigate to http://localhost:3000 in your browser to view the app.

Technologies Used
- React
- React Router
- Local Storage
- CSS, HTML and JAVASCRIPT
